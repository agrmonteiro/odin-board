# Odin Board

Gerenciador de contas para jogos idle no Windows. Abra várias contas na mesma janela, cada uma com sua própria sessão. O app é distribuído em ZIP portátil.

## Download

1. Na [página de versões](https://github.com/agrmonteiro/odin-board/releases/latest), baixe o arquivo cujo nome termina em `Windows-x64.zip`.
2. Extraia todo o conteúdo em uma pasta com permissão de escrita.
3. Abra `Odin Board.exe` na pasta extraída. O app cria a pasta `Dados` ao lado do executável.

## Atualização

A partir da 0.2.3, feche o app e copie a pasta `Dados` para a pasta da nova versão antes de abrir o executável.

Para migrar da 0.2.2 ou anterior, feche o Odin Board e copie o conteúdo de `%APPDATA%\Odin Board` para a pasta `Dados` ao lado do novo executável.
